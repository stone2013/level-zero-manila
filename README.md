# LEVEL 0 · 零层

面向手机的 HTML 3D 生存探索游戏，包含程序生成迷宫、食物路标、饱食度与口渴系统，支持 PWA。

手机优先的 HTML / WebGL PWA 探索原型。Three.js 已打包在本地，不依赖 CDN，无服务器、无账号数据、无遥测。

## 运行

用静态 HTTP 服务打开 dist 目录，例如：

    python3 -m http.server 4173 --directory dist

浏览器访问 http://localhost:4173。不能直接双击 index.html：ES 模块需要 HTTP 服务。
生产环境请使用 HTTPS，以启用 PWA 离线缓存。首次成功在线加载全部资源后才具备离线启动条件。清除站点数据、浏览器主动回收存储或从未完整缓存的设备不能保证离线启动。

iPhone：在 Safari 打开游戏，分享 → 添加到主屏幕。没有声称完成真机安装或 iOS 离线验证。横屏更舒适，竖屏也可操作。

## 操作

- 手机：左摇杆移动，右侧空白区域拖动观察。交互、放下、进食、饮水为独立按钮；按住快走。
- 电脑：WASD 移动，点击画面后鼠标观察。E 交互，Q 放下食物，F 进食，R 饮水，Shift 快走，Esc 暂停。
- 暂停、失焦或切到后台时停止生存计时与移动；回到游戏后手动继续。
- 重新生成会重置整个探索。当前原型不保存进行中的关卡。

## 玩法

每局生成 7×7 连通迷宫，加入少量普通回路。在右侧边界选距离起点最远的格子作为马尼拉房间入口。普通通路始终可解；异常回环是独立的可选分支，不替换必经道路。

开始有 4 份干粮、0 瓶饮用水。所有食物具有稳定编号；放下、拾回、吃掉不会生成复制品。异常空间只平移玩家，不移动路标。马尼拉房间有两瓶有限的水和一张纸条。房门需要手动操作，门完全关闭且玩家在室内后，连接才会改变；重新打开并走进灰色出口完成本次原型。

## 纹理（1.1.0）

原始 PNG 完整保留在 assets/source/。运行时使用 dist/textures/ 内的 1024×1024 WebP，总计约 864 KiB。墙面按 2.5 米、地毯按 2 米的统一尺度铺贴，短墙和马尼拉房间地面不会被拉伸成不同密度。

天花原图并非精确无缝纹理。渲染时只使用一块吸音板的内部区域，映射到向下的独立实例化面板，面板之间保留 25 毫米灰色网格缝。没有对原图进行修补，也没有声称贴图完美无缝。

Three.js 几何 / UV 测试在 Node 中执行，不能代替真实浏览器画面或手机真机验证。

## 主菜单与光影（1.2.0）

主菜单在真实 Three.js 迷宫门廊上绘制文字，并未用概念效果图替代三维场景。开始探索会生成新种子；继续探索只恢复当前页面内暂停的游戏。设置支持环境音开关和省电分辨率。浏览器不允许任意页面关闭自身，所以「退出游戏」说明如何关闭页面，并明确本轮进度不会持久保存。

光照固定为 1 个半球光和 1 个方向光。荧光灯使用不受环境照明影响的自亮外观；没有给每盏灯分配点光。明确禁用实时阴影、全局照明、镜面反射和全屏后期效果。墙脚和墙顶采用根据每块墙体自身尺寸生成的顶点渐暗，属于近似接触暗部，不是准确阴影，也不烘焙具体灯位或整个迷宫。

手机 DPR 最多 1.35，总像素最多约 110 万；桌面 DPR 最多 1.6，总像素最多约 200 万。省电选项将每个方向的分辨率乘以 0.75。静态灯具与装饰盒体按材质实例化，活动门和物品独立保留。菜单和暂停画面最多约 12.5 次/秒绘制，游戏保持浏览器正常帧调度；后台不绘制。这里的帧调度上限不是实测 FPS。
