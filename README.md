# LEVEL 0 · 零层

手机优先的 HTML / WebGL PWA 探索原型。Three.js 已打包在本地，不依赖 CDN，无服务器、无账号数据、无遥测。

## 运行

用静态 HTTP 服务打开 dist 目录，例如：

    python3 -m http.server 4173 --directory dist

浏览器访问 http://localhost:4173。不能直接双击 index.html：ES 模块需要 HTTP 服务。
生产环境请使用 HTTPS，以启用 PWA 离线缓存。首次成功在线加载全部资源后才具备离线启动条件。清除站点数据、浏览器主动回收存储或从未完整缓存的设备不能保证离线启动。

iPhone：在 Safari 打开游戏，分享 → 添加到主屏幕。没有声称完成真机安装或 iOS 离线验证。手机和平板需横屏使用；竖屏会显示旋转提示并冻结当前探索。

## 操作

- 手机：左摇杆移动，右侧空白区域拖动观察。靠近门或物品点「交互」；按住「快走」。点「背包」后选中物品，进食、饮水、查看手机资料或放下。
- 电脑：WASD 移动，点击画面后鼠标观察。E 交互，Tab / I 打开背包，Shift 快走。背包内 Tab 切换焦点，I / Esc 关闭背包；探索中 Esc 暂停。
- 背包打开时，移动、饥渴、门与接近事件计时暂停；关闭背包仅解除背包暂停。失焦或切到后台后仍需手动继续。
- 重新生成会重置整个探索。当前原型不保存进行中的关卡。

## 玩法

玩家移动时，后室向四周持续分块生成，远处场景会卸载。当前普通区块按种子和世界坐标生成；空间回环的连接仍可能改变。已放下的物品独立保留。中央保留原来的 11×11 迷宫、可选异常回环和一条保证可走通的马尼拉路线，继续向外探索也不会碰到整个世界的外墙。

开始有 4 份干粮、1 部满电手机、0 瓶饮用水。所有物品具有稳定编号；手机占 1 格，电量随同一实例保留。放下、拾回和食物消费不会生成复制品。异常空间只平移玩家，不移动路标。马尼拉房间有两瓶有限的水和一张纸条。房门需要手动操作，门完全关闭且玩家在室内后，连接才会改变；重新打开并走进灰色出口完成本次原型。

## 文件

- dist/game.js：与渲染独立的迷宫、碰撞、生存、物品、房门模拟
- dist/world.js：确定性分块迷宫、有限布局缓存、逐帧渲染生成调度

## 主菜单与光影（1.2.0）

主菜单在真实 Three.js 迷宫门廊上绘制文字，并未用概念效果图替代三维场景。开始探索会生成新种子；继续探索只恢复当前页面内暂停的游戏。设置支持环境音开关和省电分辨率。浏览器不允许任意页面关闭自身，所以「退出游戏」说明如何关闭页面，并明确本轮进度不会持久保存。

光照固定为 1 个半球光和 1 个方向光。荧光灯使用不受环境照明影响的自亮外观；没有给每盏灯分配点光。明确禁用实时阴影、全局照明、镜面反射和全屏后期效果。墙脚和墙顶采用根据每块墙体自身尺寸生成的顶点渐暗，属于近似接触暗部，不是准确阴影，也不烘焙具体灯位或整个迷宫。

手机 DPR 最多 1.35，总像素最多约 110 万；桌面 DPR 最多 1.6，总像素最多约 200 万。省电选项将每个方向的分辨率乘以 0.75。静态灯具与装饰盒体按材质实例化，活动门和物品独立保留。菜单和暂停画面最多约 12.5 次/秒绘制，游戏保持浏览器正常帧调度；后台不绘制。这里的帧调度上限不是实测 FPS。

## 横屏模式（1.3.0）

- PWA manifest 声明 landscape。支持方向锁的浏览器在开始、继续或点击「尝试自动横屏」时请求横屏；普通浏览器可先进入全屏，已安装 PWA 不重复申请全屏。
- 手机和平板实际可用视口为竖屏时，整个界面被旋转提示覆盖，底层界面设为 inert。移动、视角、动作、键盘输入以及生存、房门与接近事件计时全部冻结；已有触控捕获与按键立即释放。
- 旋回横屏只解除方向暂停。手动暂停、后台暂停、纸条、设置和结束状态保持原状。不会补算竖屏或后台经过的时间，也不会把窄桌面窗口当成手机强制阻挡。
- iPhone / Safari 的网页方向锁不能保证生效，按钮只在 API 存在时显示。请把设备横过来；如果仍不旋转，关闭系统竖屏锁定。没有用 CSS 旋转整个画布来伪装系统横屏。
- 更新到 v1.3.0 使用新缓存。已有版本收到更新后，需关闭所有游戏标签页及主屏幕应用，再重新打开；为保持当前局资源一致，不强制替换正在玩的版本。

- 玩家位置执行刚性平移，朝向、视角与本次移动剩余量保持。食物编号、对象身份与世界坐标不改，可以绕回找到同一份路标。没有复制路标或绘制全路线提示；去掉原来的黑屏闪烁，使用短暂灯声变化。
- 回环发生在 U 形遮挡转角，包含转弯，不是完全笔直走廊。三个连接口使用相同的局部墙纸/地毯 UV、灯具外观和局部烘焙，降低切换时的差异。尚未通过真实 GPU 画面验收，不宣称完美无缝。
- 门口两侧及门楣的走廊朝向表面使用现有小而淡的墙纸，并采用外侧迷宫光照；朝向马尼拉房间的一面继续使用原房间材质。门楣补齐至 1.8 米，厚度统一为 0.16 米，补齐顶端收边。房间组在空间变化后仍保留。

## 持续分块生成（1.6.0，2026-10-06 获准发布）

玩家移动时向周围持续生成普通区块，远处几何会卸载；没有原来 55×55 米地图的全局外墙。马尼拉房间、有限物资、原空间回环及物品实例独立保留。放下的手机和食物不会因为区块卸载而被移动、复制或重新生成。

- 碰撞布局最多缓存 16 个区块。渲染区为 7×7 格、35×35 米，按真实视野请求，最多保留 49 个已完成/待完成区，包含最近看过区域的缓存。绝对上限为 2,401 个地面格，常见当前视野少于这个上限。
- 保留原来的雾起止 16/80 米、76° 垂直视角和 65 米远裁剪。不用更浓的雾遮挡未生成区域。初始化时显示生成提示；后续视野未准备好时保留上一完整画面并短暂停止探索。快速转身或进入未缓存区域可能出现加载等待。
- 使用真实相机视锥，包括视口宽高比、俯仰和转向，避免只检查正前方而漏掉宽屏两侧。支持宽高比不超过 4:1 的窗口；超过时明确提示缩窄窗口，不偷偷省略可见区块。
- 每帧加载工作软目标为 8 毫秒 / 最多 48 个生成步骤；正常探索为 3 毫秒 / 最多 24 步。单步或垃圾回收可能超过软目标，这不是实测 FPS 或绝无卡顿的保证。初始化、快速转向时可能比旧版等得久。
- 新视野等待时，移动、饥渴、门、接近计时和手机设备时钟都暂停；后台和竖屏也不推进生成。空间回环会预先请求落点，若落点未完成则保留玩家在原侧，加载后再通过。
- 保留主菜单镜头、光照算法、淡化墙纸、黄色天花板、两盏全局光与分辨率预算。区块卸载只释放自己拥有的几何/实例资源，不释放共享纹理或马尼拉房间。

局部坐标与程序测试覆盖到正负 10 公里。这是受计算机数值精度和设备性能约束的持续生成，不是数学意义上的无限。真实手机加载时长、帧率、发热与 GPU 画面仍需实测。详见 CLEAR_VIEW_REPORT.md 与 PHONE_STREAMING_REPORT.md。

## 随身手机与充电线（1.6.0，2026-10-06 获准发布）

- 开局自带一部 1×1 满电手机。背包选中后点「查看资料」，进入离线目录：零层、马尼拉房间，以及残缺的未知出口记录。内容为本游戏原创简短手记，明确属于游戏改编，不含定位、地图、联网搜索或可玩的新层级。
- 亮屏阅读按每秒 `100/480` 个百分点耗电，满电约读 8 分钟；收起手机不耗电。没电后隐藏正文并提示去马尼拉桌边充电，不会结束探索。放下、拾回、整理及空间连接变化都保持同一手机 ID 与电量，手机不能食用。
- 马尼拉长凳旁新增墙上插座和固定充电线。手机在背包内、玩家在端头 1.3 米内且没有墙体遮挡时，点交互或手机内「接上充电线」连接。离开范围、放下手机或手动断开后停止充电；不会远程充电，也不会生成新手机。
- 按每秒 `100/40` 个百分点充电，空电到满电约 40 个有效前台秒。充电时屏幕使用外接电源，不再另扣阅读电量。电量限制为 0–100%。
- 背包和手机暂停探索，但前台设备时钟独立运行，所以可以在手机界面看着电量增加。菜单、设置、纸条、手动暂停、后台、失焦、竖屏及视野加载等待冻结设备与探索；不补算离开期间的时间。
- 手机内 Esc / I 先返回背包，再按一次关闭背包；Tab 保留在可见手机控件内。短横屏可滚动阅读，关闭和充电操作保留至少 44 CSS 像素。
- 当前会话没有新增存档功能，刷新或重新生成仍重置整局。
